## Details

### Lab Act 1
So basically, we started with the foundational setup and super clean UI design for our NUBD Exchange e-commerce app. We added custom Poppins typography and NU Shield branding assets so it looks totally aesthetic and fresh.

### Lab Act 2
Here, we integrated the DummyJSON API to fetch and display the product catalog grid with a real-time search bar, super convenient right? We also added a product details page plus a Light/Dark mode theme switcher using Provider so users can toggle their vibe.

### Lab Act 3
For this one, we made all the shopping cart features like quantity controls, subtotal calculations, and smooth navigation back to product details. We also integrated the CartService API connection and added a FloatingActionButton for customer chat, so high-key responsive!

### Lab Act 4
Lastly, we implemented persistent authentication and login flow using SharedPreferences and UserService API so users stay logged in. Plus, we designed a custom animated splash screen, a dynamic user profile page, and user-specific cart loading—literally so legit!

### Lab Act 5
Now for this one, we integrated Firebase Authentication into our app with dual-login support so users can choose between DummyJSON and Firebase! We built a dedicated 8-field sign-up screen with complete validation, added persistent sessions across app restarts, and enabled full profile management so users can update their username, change passwords with reauthentication, and even delete their account—super clean and production-ready!

### Lab Act 6
For this one, we integrated Cloud Firestore to build a complete real-time one-to-one messaging system with deterministic chat room IDs! We added a registered-user directory with live search filtering, excluded the logged-in user to prevent self-chat, designed animated sender and receiver chat bubbles with sending, sent, delivered, and seen status checkmarks, hooked up the FloatingActionButton for easy conversation access, and secured the backend with strict, participant-scoped Firestore security rules—literally peak real-time chat!
